# AGENTS

This repository is collaboratively developed by humans and AI assistants.

- Feature 1 establishes the application foundation only.
- AI assistants must:
  - Respect existing documentation.
  - Implement only explicitly approved features.
  - Avoid introducing speculative product functionality.
  - Document architectural and security decisions.

Future features (trips, flight data, recovery plans, authentication, etc.) MUST NOT be implemented without explicit approval.
